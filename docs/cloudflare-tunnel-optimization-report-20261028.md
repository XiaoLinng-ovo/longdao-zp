## 2. 实现内容

生产网关提供：

- `web/dist` 静态文件服务。
- 仅对浏览器 HTML 请求进行 SPA 路由回退；不存在的 JS/CSS/API 不会返回 `index.html`。
- `/api/*` 到 `127.0.0.1:3100` 的同源 HTTP 代理，保留方法、请求体、Cookie、Origin 和查询参数。
- `/funasr-stream` 到 FunASR `/stream` 的 WebSocket 原始升级代理，保留查询参数和升级头。
- 内容哈希 JS/CSS 的一年 immutable 缓存；HTML 和无哈希资源重新验证。
- Brotli/gzip 协商压缩文本资源。
- URL 解码、路径归属检查和基本错误响应，避免静态目录越界。

没有把 `vite preview` 作为长期公网服务，也没有删除或改造当前 Vite 开发入口。
