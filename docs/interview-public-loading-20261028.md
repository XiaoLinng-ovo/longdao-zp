- 生产网关为支持 gzip 的客户端流式压缩 JSON；保留 Cookie、状态码、请求路径、Origin，删除旧 Content-Length 并设置 Vary。已有压缩响应不重复压缩，不修改音频 Range 或 WebSocket。
- 面试列表及安排选项统一使用现有 interviewRequest，20 秒后中止请求并显示明确错误，可重新点击刷新。不自动重试写操作，不放宽权限或安全策略。
- 使用独立构建目录验证后复制新版静态资源，保留旧哈希资源和 index 备份。
- 发现旧网关有语音连接时未重启；另开 5181 作为压缩备用入口。随后再次检查旧网关无 Established 连接，才仅重启本项目 5180 前端网关，原 Cloudflare 连接器和公网地址不变。API、Worker、语音服务和数据库未重启，未迁移或改写业务数据。
