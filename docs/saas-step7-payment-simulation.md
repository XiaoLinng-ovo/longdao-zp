# 第七步：订单与支付模拟验收

交付日期：2026-10-13。用户选择先做模拟测试，后续接入支付宝/微信。本阶段已经部署本机并完成真实浏览器验收；未接入官方支付渠道，不发生真实收款。

## 入口与操作

企业所有者或管理员登录并选择企业后，进入左侧「企业管理 → 支付流程测试」，路径 /enterprise/billing-sandbox。普通成员不能访问；平台运营授权不能替代企业管理员身份。

1. 选择「支付宝场景（模拟）」或「微信场景（模拟）」，创建模拟订单。
2. 点击「模拟支付成功」，观察模拟权益及订单状态；点击「重发成功通知」，应提示未重复发放权益。
3. 点击「模拟全额退款」，填写 2–300 字原因并确认，查看已退款状态及模拟权益变化。
4. 另建订单可验证失败、取消；到期后刷新页面可确认订单超时。超时或取消后到达的成功通知，以及权益版本冲突的成功通知进入待核对，不自动覆盖权益。

## 已完成的实现

- 服务端固定商品与金额快照，企业隔离、实时成员/服务状态校验、Origin/CSRF 写保护。
- 持久创建幂等键、重复/并发通知去重；金额、币种、商户、渠道、企业及交易事件一致性验证。
- 订单状态与权益发放、通知事件、审计在同一事务内提交；故障时回滚。
- 模拟成功、失败、取消、超时、退款与待核对状态；订单分页及网络异常后的同键创建重试。页面刷新后不承诺保留未完成创建的客户端幂等键。
- 模拟适配器使用进程内随机密钥的 HMAC 协议；该协议不是支付宝/微信官方协议，也没有开放公共模拟回调接口。
- 模拟渠道仅 mock_alipay / mock_wechat，真实渠道参数拒绝。尚无自动过期任务、待核对人工放行、正式商户对账或自动续费。
