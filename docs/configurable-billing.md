# 可配置套餐与算力计费

更新日期：2026-11-12。本次新增充值与订阅分栏、默认长期有效的算力商品、余额来源展示和历史付费额度转换，已在隔离环境开发验证，尚未部署正式环境，也未启用正式扣费或转换正式历史余额。此前 2026-11-10 分钟计费的本机发布记录保留在 deployment-billing-minutes-20261110.md，不代表本次 0091 迁移已经上线。

## 后台操作

系统管理员进入“支付与商品管理”。企业内所有有效成员共享企业的业务权限、套餐容量与算力额度；企业成员不能修改平台计费规则、平台模型凭据或自行接入模型。

### 商品与定价

每个商品可以单独设置名称、售价、有效期，以及以下权益：

| 项目 | 订阅套餐 | 算力增购包 |
| --- | --- | --- |
| 席位、岗位容量 | 手工填写 | 沿用企业现有容量 |
| AI 点数、转写分钟数、OCR 页数 | 独立填写 | 独立填写，至少一种大于零 |
| 发放方式 | 一次或按月 | 一次 |
| 到期规则 | 每期到期或结转至商品期限结束 | 默认长期有效；管理员也可明确设置有限期限 |
| 企业服务期限 | 按订阅规则开通或续费 | 保持现有服务期限 |

修改已发布商品时，使用“复制发布新版本”，填写修改原因。已有订单保留购买时的价格和权益，不读取后续商品的新配置。新商品需上架后供企业购买。

商品说明和展示排序同样由平台管理员配置，说明会作为订单快照保存，排序数值越小越靠前。算力增购包必须包含至少一种非零额度，只能一次到账，不配置席位、岗位、模块或按月结转。支付截止时间与额度有效期是不同概念；长期额度不代表支付二维码永久有效。

按月发放以购买权益的起始时间为锚点，按上海时区每月递进，不是每月一日统一清零。未来月份额度会预先写入但在生效时间之前不可使用；关闭结转时，每期额度至下一期或商品期限结束时到期，开启结转时保留到商品期限结束。

### 算力与试用规则

平台管理员可编辑总扣费开关，以及九类业务各自的开关、扣除资源、扣除数量与单位大小：

| 业务 | 后台配置计量单位 |
| --- | --- |
| 简历分析 | 次 |
| 岗位说明生成 | 次 |
| 职位描述生成 | 次 |
| 面试题生成 | 组或本次请求 |
| 回答与阶段分析 | 次 |
| 面试总结 | 次 |
| 转写后处理 | 次 |
| 面试音频转写 | 分钟 |
| 简历 OCR | 页 |

单次扣除量为“向上取整（业务量 ÷ 单位大小）× 每单位扣除数量”。音频采用同一场面试的已覆盖时长计算增量：实时双音轨、后续整段转写与说话人重识别在同一时间区间内不会重复扣音频额度。同一场音频会话从首次计量起使用固定规则快照。

试用设置包括：天数、席位、岗位容量，简历上传/面试/AI 生成次数，以及 AI 点数、转写分钟数和 OCR 页数。新企业创建时确定试用期限与容量，修改规则不会覆盖已有企业的期限和容量。试用次数读取当前限制；算力额度在首次领取时确定，设为零也记录已领取，后续改大不自动重复发放，补额请使用手工发放。

成本保护参数包括每家企业的最大并发、每日 AI 点数、单次输入字符与单次输出 Token 上限。额度不足时在外部任务派发前拒绝，不允许余额透支。普通表单操作、查看已有结果及读取历史记录不因上述算力扣点而收费。扣点单位用于产品计费，不等同于服务商实际 Token 账单；正式价格需要结合实际成本核算，不能仅凭默认值认定盈利。

填写发布原因后点击“发布新规则”。规则追加为新版本，保留历史；保存时校验读取的版本，其他管理员已更新时会拒绝覆盖并提示刷新。已开始的任务保留各自快照，后续新任务采用新版本。总扣费开关默认关闭；关闭期间不扣减额度，但并发、每日用量、输入字符及输出 Token 上限仍生效，避免免费调用失控。每日 AI 限额使用独立的保护计量，不因关闭扣费而归零。原有服务、权限和试用次数限制仍独立生效。

### 手工补发额度

1. 以企业名称或企业 ID 查找，选择“发放企业”。搜索条件变化会清除原选择，避免误发给旧企业。
2. 选择额度类型，填写正整数数量、未来到期时间与发放原因；勾选“长期有效额度”时无需到期时间，明确提交空期限。转写数量在页面以分钟输入，允许精确到整数秒的分钟小数。
3. 点击“发放额度”。网络失败后原样重试复用同一请求标识，避免重复发放；改变输入视为另一笔发放。

### 异常任务核对

后台列出结果待核对任务和预占超过十五分钟的任务，最多一百条。平台管理员核实业务结果与服务商记录后，填写依据并选择“确认已完成，结算额度”或“确认未完成，退回额度”。每次操作保留审计记录，同一任务不能重复退额。

| 状态 | 额度与重试处理 |
| --- | --- |
| 处理中（reserved） | 额度已预占，禁止同一任务再次派发 |
| 已扣除（settled） | 结算成功；保存了结果的同一请求重放缓存，不再次调用模型 |
| 已退回（released） | 明确失败已退额，可按相同内容发起下一次尝试，旧尝试保留 |
| 待平台核对（uncertain） | 网络、结算等结果有歧义，保留预占，核对前禁止重复派发 |

人工确认成功不会凭空恢复丢失的业务结果；不能将手工结算视为再次调用模型的授权。保留预占可能占用并发，须及时核对异常任务。

## 企业侧体验与模型约束

“充值与订阅”拆为“算力充值”和“服务订阅”两个入口。算力商品展示价格、非零额度、有效期、到账方式和商品说明，不展示席位、岗位。订阅商品展示期限、自定义容量、附带额度及发放/到期规则。订单支持按两种类型筛选。容量小于当前用量的订阅不可购买；企业服务无效时禁止仅买算力，保留续订入口。

“企业 AI 用量”展示三类共享可用余额、长期余额、预占量、最近到期时间、最近一百条额度批次来源和最近五十条任务。扣减先使用最早到期的有效额度，长期额度最后使用。企业服务到期不删除长期余额，服务恢复后可继续使用。成员变更企业时丢弃旧请求响应，避免显示其他企业的数据。平台模型只由系统管理员配置，运行时忽略企业旧模型配置；接口同样限制写权限，不能仅靠隐藏页面控制。

### 历史付费额度转换

平台管理员在“商品与定价”下输入增购订单 ID，先预览剩余额度，再填写依据确认。只处理正式已到账增购订单中已生效、未过期、未冻结、有剩额且没有预占或待核对占用的批次；试用、订阅附带、已到期及已撤销额度不自动转换。余额或订单状态变化后必须重新预览。

转换仅清空可转换批次的到期时间，不补发已消耗部分、不改变订单售价和原商品快照。原到期时间、转换时剩余额度、操作人和原因写入独立记录及审计日志。正式历史额度没有自动批量迁移。

永久充值仅增加额度，不改变订阅容量、期限或权益版本；重复支付通知不重复发额。全额退款前仍校验使用和预占，退款中冻结相应额度；结果不确定时继续冻结并等待核对，不能当作退款失败直接恢复。

音频转写统一通过 API 的 /funasr-stream 网关，校验登录、来源、企业成员资格和面试归属，再连接平台配置的识别服务。客户端不能通过自定义识别地址绕过计量。单场同音轨互斥，双音轨共享场次并发。实时额度不足停止转写，独立录音仍可保留；后续转写也须通过额度校验。

## 转写按分钟计量

后台商品额度、首次试用额度、手工补额、扣费规则，以及企业余额和流水均以分钟填写和展示。默认每累计一分钟扣除一分钟额度，累计不足一分钟向上取整：1 秒、59 秒、60 秒均扣 1 分钟，61 秒扣 2 分钟。管理员仍可自行修改每个计量单位的分钟数及扣除额度。

同场面试先合并有效音频时间区间，再对总时长取整，不对每个分片或音轨单独取整。双音轨重叠、重新转写已覆盖片段不重复扣费。

底层保留整数秒账本与原接口资源键 interview_seconds，页面输入提交时换算一次；旧余额、已售商品、订单快照和进行中会话均不改写。历史不足整分钟的数据保留余量，以小数分钟展示，循环小数使用“≈”标记；未经编辑再次发布能精确保留原秒数。迁移仅将未调整的默认每秒扣一秒规则发布为新的每分钟扣一分钟规则，不覆盖管理员已自定义的价格或开启扣费开关。
