## 接口与数据边界

- `GET /api/v1/admin/ai-usage`：page、operation、state、reviewOnly、from、to。时间为严格 UTC ISO 格式，开始含、结束不含；重复参数或非法区间返回 400。
- `GET /api/v1/admin/ai-usage/:taskId/reviews`：读取当前企业核对记录。
- `POST` 同路径：key（UUID）、outcome、note（去除首尾空白后 2–1000 个 Unicode 字符）。
- `0038_ai_usage_diagnostics.sql`：添加诊断字段及独立备注表，不重写历史账本。

诊断字段不保存密钥、URL、原始输入、错误文本或上游响应体。备注由用户主动填写，页面提示不要填写密钥或简历敏感信息。次数不等于 Token 或金额，失败请求是否产生模型服务商费用需查服务商记录。
