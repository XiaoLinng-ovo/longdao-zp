- 重放必须先通过现行企业、岗位及业务角色授权；企业暂停、成员资格或角色变化不会被旧通用幂等响应缓存绕过。
- 明细 20 条分页，可刷新；刷新失败清除旧数据，企业切换旧响应不会污染新企业。

## 状态语义与费用边界

- reserved：已记录任务、调用处理中。超过 10 分钟仍未完成时只读报告显示待对账，不自动释放或重试。
- settled：模型生成且业务结果保存完成，成功次数 1；持久保存生成结果供同操作重放。
- released：模型明确 HTTP 拒绝，未完成成功生成，成功次数 0。不是服务商退款承诺。
- uncertain：超时、格式异常、业务保存或账本写入歧义，成功次数 0，需核对服务商及业务记录。
- 写失败且错误标记也无法保存时保留 reserved，保留原错误，不再自动发起外部请求；成功结算 UPDATE 未影响一行也不得假报成功。

本批只覆盖升级后使用本企业模型的岗位说明书 / JD。本地模板、连接测试、历史调用、面试、简历分析、语音转写不计入；这些原业务功能没有因此关闭。未开放平台托管模型、价格、余额、购买、真实支付或自动续费。模型服务商仍可能计费，以实际服务商记录为准。

「待对账」当前是异常发现与防重复调用能力：未实现人工确认、自动结账、服务商账单导入或退款工具，不把告警冒充完整对账闭环。

## 数据与权限

迁移 0036_ai_usage_ledger.sql 仅新增 ai_usage_tasks 表与企业时间索引。企业、操作者、业务类型、资源、标识及输入摘要约束任务归属和唯一性。

公开给企业管理员的 GET /api/v1/admin/ai-usage 仅返回用量元数据，不返回生成结果、输入摘要、操作标识或密钥。任务内部为了持久重放保存完整生成后业务结果，并非所有数据库字段都只是元数据。原始提示词和模型凭证不另存入此账本，但生成结果本身可能包含客户业务信息；数据库、备份及未来导出必须按客户敏感数据管理。

结果缓存的保留期、用户删除及数据导出策略仍待后续制定。不能在删除策略确定前把结果永久保留当作商业化最终方案。
