# 企业管理员与企业 AI 配置

## 权限与数据范围

- 系统管理员由后台绑定身份判定，可管理全部企业、账号、服务状态，指定企业主管理员并授权或撤销平台模型共用。
- 每个企业仅一名主管理员（owner），可设置多名企业子管理员（admin）。管理员仅管理本企业成员、部门、AI 配置及企业用量，无平台运营权限。
- 主管理员可在“企业成员”将普通用户设为子管理员、撤销子管理员、停用或恢复子管理员，也可生成子管理员邀请码。仅主管理员可任免或修改子管理员；子管理员只能编辑、停用、恢复普通成员和邀请普通成员，不能修改自己、其他管理员或交接主管理员。
- 企业身份仅更新当前企业的成员关系，不授予账号全局或平台权限；权限变更写入目标企业审计日志，并沿用现有切换前镜像规则。
- 普通成员共享当前企业的业务数据及生效配置，不能更改企业 AI、成员和部门配置。
- 企业停用成员只撤销该企业访问，不影响账号的其他企业；平台停用账号影响全部登录和业务访问。
- 主管理员交接为事务操作，原主管理员降为普通成员。历史重复 owner 保留创建者优先的一名，其余保留为兼容 admin。缺少可信创建者或管理员的企业不随机提权，由系统管理员指派。

## AI 来源

- 企业管理员在“企业管理 / AI 模型配置”（/enterprise/ai）选择企业自配或平台共用，同企业成员统一使用。
- 企业自配地址固定为 https://ai.longdaoec.com，OpenAI 兼容请求使用 /v1 路径。自助请求只能修改 API Key 和模型。
- 平台共用必须先由系统管理员在用户管理的所属企业中授权，再由企业管理员选择来源。授权以企业为范围，不借用其他企业密钥。
- 未配置、清除密钥或撤销平台授权后明确报配置不可用，不自动回退，也不隐式消耗平台密钥。
- 迁移保留已有平台授权；已启用且完整的企业自配继续优先。不自动启用历史未启用密钥。
- 密钥加密入库，读取仅返回掩码。留空保存保留当前密钥，清除需确认。连接测试仅使用企业自配密钥。

## 套餐与 OCR

取消新增算力包销售、算力扣减、三次 AI/简历/面试试用限制和重置入口。保留服务期限、席位与岗位限制，以及历史订单、额度、退款、用量、对账和审计数据；保留并发及输入输出等技术保护。

OCR 使用服务器端 PaddleOCR，不要求用户电脑安装 OCR，也不依赖企业聊天模型密钥。生产服务器仍须具备可用 OCR 服务及模型文件；OCR 之后的 AI 简历分析、评分等按企业所选模型执行。

## 发布与验证

按现有受审阅的备份、恢复演练、精确迁移批准流程依次应用 0107、0108，并发布 API、Worker、前端和结构契约。迁移不删除历史业务记录。

保留原 AI_CONFIG_ENCRYPTION_KEY 和环境配置，禁止重建加密主密钥。旧企业冻结凭据只兼容 0107 新增的默认 false 字段，不忽略其他数据变动。

隔离回归脚本 scripts/test-enterprise-ai-self-service-isolated.mjs 使用独立 PostgreSQL 和合成数据，覆盖企业权限、交接与指派、即时停用、跨企业隔离、模型来源授权和超过三次的零扣减。不会连接业务库或请求真实模型。
