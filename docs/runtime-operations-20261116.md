## 已实现的边界

- scripts/runtime-config.mjs 只读合并配置；显式 ENV_FILE_PATH 不存在就报错，不回退其他业务环境文件。API/Worker 托管模式禁止二次加载不同配置。
- scripts/runtime-doctor.mjs 检查配置契约、明确数据库目标、完整迁移账本、公司结构、已登记对象位置和公司数据阶段。普通启动也检查数据阶段；切换前比较差异，切换后检查冻结旧基线及公司归属/外键，不要求两侧永远相等。--audit 额外分类差异并查看任务状态，不等同于已经完成排空。
- 普通启动只运行独立发布目录中的预构建产物，不安装、不编译、不迁移、不 seed、不改 .env，不停止外部端口占用者。
- runtime:prepare 在全新目录离线安装锁定依赖、构建 API/Worker/Web、生成 SHA256 清单。外链依赖和内容变化会被拒绝；失败目录保留且不修改活动指针。发布目录不是只读文件系统，校验不能替代账户权限控制。
- Web 使用已有静态网关及 HTTP/WebSocket 代理。完整就绪同时验证 API/Worker 发布版本、Web 内容及同源 API ready。
- PM2 7.1.2 托管三角色，关闭 watch；每角色十分钟最多三次启动，超过预算退出 78；瞬间不稳定退出另有 PM2 上限和指数退避。状态异常后需要修复、显式 stop/start，不无限重试。
- API/Worker 每十秒执行有界数据库探测，连续三次失败优雅停止并熔断。此策略不是无人值守的无限自动恢复。
- Windows shutdown IPC + 信号均进入停止流程，等待启动中资源交接，应用停止期限 25 秒、管理器强制期限 30 秒。超时属于异常，不能冒称在途业务已完成。
- API/Worker/Web/controller 日志分别轮转，单文件 5 MiB、四个历史副本，脱敏常见凭据并避免输出结构化业务对象。PM2 共享守护器本身的 pm2.log 不属于这些实例日志，其容量需另行运维。
- status 区分 endpointsReady、managed 和 ready；stop 不依赖可用的配置文件。诊断和状态不会重建已退出的守护器。
- 固定 PM2 版本达到上限后可能保留 waiting restart 文本，但 PID 已为零且不再调度。status 保留 managerStatus 原值，并按该版本的明确终止标记展示 circuit-open、退出码和人工恢复原因；不会把正常退避等待误标为熔断。

Windows 上 PM2 使用共享命名管道，即使 PM2_HOME 不同也不保证隔离。所有管理操作必须校验实例名、执行路径和实例 ID，禁止 pm2 kill、delete all、全局 resurrect。外部 PostgreSQL、OCR、语音进程不归此控制器所有。

## 日常命令

在项目根目录运行，只读操作可以立即使用：

```powershell
npm run runtime:doctor -- --audit
npm run runtime:status
npm run runtime:logs
```

完成维护并选定明确配置后才执行：

```powershell
$env:ENV_FILE_PATH = 'D:\approved-runtime\business.env'
$env:RUNTIME_HOME = 'D:\approved-runtime\instance'
npm run runtime:prepare
npm run runtime:start -- --release '<runtime:prepare 输出的独立候选目录>'
npm run runtime:status
npm run runtime:stop
```

路径为示意，不要直接照抄为真实配置。正常 start 不构建，首次必须指定候选目录；后续使用活动指针。重复 start 仅在发布、配置摘要和三角色状态匹配时复用。升级先停止已有实例；候选启动失败保留旧指针，但不自动恢复旧程序，更不回滚数据库。

operation.lock 残留时先核对文件记录的 PID、启动时间和命令身份，再人工处理已确认失效的锁；不要盲删锁或停止其他项目。

## Windows 登录恢复

scripts/runtime-windows-host.ps1 提供 install/status/remove。必须先完成真实实例就绪，使用绝对 StateDirectory、ProfilePath 才允许安装；不自动启用：

```powershell
powershell -NoProfile -File scripts/runtime-windows-host.ps1 -Action status -StateDirectory 'D:\approved-runtime\instance' -ProfilePath 'D:\approved-runtime\business.env'
```

安装采用当前用户登录触发、隐藏窗口、有限两次任务重试，不保存密码，不接管其他任务。它不是开机未登录即可运行的系统服务，注销/重启后的实际恢复尚未演练。真正无登录运行须单独安装和验收受控 Windows 服务；不可宣称已实现。
