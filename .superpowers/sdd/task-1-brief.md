# Task 1: Web 工程与应用壳

Create a new `web/` Vue 3 + TypeScript + Vite frontend. Add package scripts `dev`, `build`, `typecheck`, `test`; strict TypeScript, Vue plugin, Vitest. Create router with routes `/`, `/requisitions`, `/jobs`, `/candidates`, `/interviews`, `/offers`, `/reports`, `/administration`, dynamic page imports, unknown redirect to `/`. Export `createAppRouter()` and `navigationItems`; route metadata `{title, navLabel, icon}`. Implement `App.vue`, responsive `AppShell`, sidebar navigation, top bar title, base/layout CSS. Sidebar collapses to horizontal menu under 760px. Add router tests for paths, titles, redirect and metadata. Do not alter root `index.html`, server, functions, or old global state. Pages may initially use placeholder modules so all dynamic imports resolve.
